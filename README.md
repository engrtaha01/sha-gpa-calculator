# SHA GPA Calculator

SHA students ke liye simple aur fast GPA / CGPA calculator.
Vite + React + Tailwind CSS se bana hua hai.

## Features
- Semester-wise GPA calculator
- CGPA calculation
- Grade + Credit Hours se automatic calculation
- Clean aur responsive UI

## Tech Stack
- Vite
- React
- Tailwind CSS

## Run Locally
npm install
npm run dev
